# Проект автоматизации тестирования API «Яндекс Самокат»

Данный проект содержит автотесты для проверки ключевых ручек (endpoints) API сервиса **Яндекс Самокат**. Тесты написаны на **Python** с использованием фреймворка **pytest** и генерацией отчетов в **Allure**.

## 🛠️ Используемые технологии и библиотеки
* **Python 3** — основной язык разработки.
* **Pytest** — фреймворк для написания и запуска тестов.
* **Requests** — библиотека для отправки HTTP-запросов.
* **Faker** — библиотека для генерации реалистичных случайных данных (имена, адреса, телефоны).
* **Allure TestOps / Allure Report** — инструмент для визуализации результатов тестирования.

## 📋 Покрытый функционал (Что тестируется)
1. **Создание курьера (`/api/v1/courier`)**:
   * Успешное создание курьера с валидными данными.
   * Негативные проверки на регистрацию без обязательных полей (`login`, `password`).
   * Проверка уникальности логина (запрет на создание дубликата).
2. **Авторизация курьера (`/api/v1/courier/login`)**:
   * Успешный вход курьера в систему.
   * Ошибки при отсутствии обязательных полей (`login`, `password`).
   * Ошибка при попытке входа под несуществующим пользователем.
3. **Создание заказа (`/api/v1/orders`)**:
   * Параметризованный тест для проверки создания заказа с различными цветовыми конфигурациями самоката (`BLACK`, `GREY`, оба цвета, без указания цвета).
4. **Список заказов (`/api/v1/orders`)**:
   * Проверка успешного получения общего списка заказов с сервера.

## 🚀 Инструкция по запуску проекта

### 1. Клонирование и подготовка окружения
Убедитесь, что вы находитесь в корневой папке проекта, создайте и активируйте виртуальное окружение:
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 2. Установка зависимостей
Установите все необходимые пакеты одной командой из файла `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 3. Запуск автотестов
Для запуска всех тестов сбором результатов для Allure выполните:
```bash
python3 -m pytest --alluredir=allure-results
```

### 4. Генерация и просмотр отчета Allure
*(Требуется установленный в системе Allure CLI, например через `brew install allure`)*
Чтобы скомпилировать результаты в интерактивный веб-отчет и открыть его в браузере, выполните:
```bash
allure serve allure-results
```
